### 💡 Selected AI & Machine Learning Projects

**🐝 BSF Larva Growth Stage Detection & Classification** *(Bachelor's Thesis)*
`Python` `YOLOv11s` `K-Means Clustering` `TensorFlow Lite` `Flutter`
End-to-end computer vision system detecting 4 growth stages of Black Soldier Fly larvae from 21,974 annotated images, achieving 0.9723 precision and 0.8720 mAP50 — deployed on-device via TensorFlow Lite in a Flutter mobile app for offline field inference.

**🎬 AI-Powered Movie Recommender System**
`Python` `Streamlit` `Content-Based & Collaborative Filtering`
Recommendation engine combining content-based feature extraction and cosine similarity, with an interactive Streamlit app for search, filtering, and dynamic poster fetching.

**🖼️ AI-Based Image Classification Application**
`Python` `TensorFlow/Keras` `Streamlit`
Interactive image classification app powered by pre-trained CNNs, with automated preprocessing and a non-technical-friendly UI.

**🏪 Malaka Jaya Digital MSME Community Web Portal**
`PHP Native` `MySQL` `JavaScript` `Leaflet JS` `Gemini API`
Community MSME platform with 3-tier role system, merchant dashboards, OTP-secured auth, and an integrated Gemini-powered AI chatbot assistant.

**📊 Student Academic Grading System**
`PHP Native` `MySQL` `JavaScript`
Role-gated grading system with dynamic weighted scoring, real-time recapitulation, printable report cards, and Excel export.
